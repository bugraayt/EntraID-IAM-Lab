## What I did 
Created three security groups (IT-Admins, Finance-Team, All-Employees) in Microsoft Entra ID and assigned users to each based on their department and role, establishing a basic access structure instead of managing permissions per individual user.

## Why it matters 
Grouping users by function allows access to be managed at the group level rather than individually — this is a core least-privilege and scalability practice, since permissions can be granted/revoked for an entire team at once and reviewed more easily during access audits.
